# Project Files Overview

This file gives a short description of all documentation files included in the Active Directory project.  
Each file represents one major part of the setup process, from planning to troubleshooting.

---

## File Index

### **01_introduction.md**
Provides a general introduction to the project, its purpose, and what the environment aims to simulate.

### **02_preparations-and-topology.md**
Describes the initial preparations, literature review, and the network topology used in the project.

### **03_virtualization-and-installation.md**
Explains the virtualization setup in Hyper-V, the creation of the NAT switch, installation of OS, and disk configuration.

### **04_network-configuration.md**
Contains all IP configurations, DNS settings, and verification of network connectivity.

### **05_dns-and-active-directory.md**
Documents the installation of DNS, Active Directory, and the promotion of DC01 and DC02 as domain controllers.

### **06_clients-and-active-directory-structure.md**
Covers joining Windows 10 clients to the domain, installing RSAT, and creating the basic AD structure with OUs and templates.

### **07_group-policy-and-drive-mapping.md**
Explains password policies, folder redirection, and the creation of drive mappings using Group Policy Preferences.

### **08_project-echo-and-departments.md**
Describes the setup of Project Echo and the department OUs used to organize users and permissions.

### **09_troubleshooting-and-lessons-learned.md**
Summarizes the issues encountered, how they were solved, and what was learned during troubleshooting.

### **10_conclusions-and-reflection.md**
Final conclusions about the project, including personal reflections and key takeaways from the work.

### **README.md**
The main project overview for GitHub.  
Summarizes the environment, what was learned, technologies used, and the structure of the repository.

---

## Purpose of This Index

This file helps readers navigate the project more easily.  
Each `.md` file represents one logical step in building the Active Directory environment, and together they form a complete documentation package.
